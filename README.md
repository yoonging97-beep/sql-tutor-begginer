# SQL Tutor

브라우저에서 바로 SQL을 연습하는 입문자용 학습 페이지예요. 설치 없이 `index.html` 하나로 동작해요.

## 주요 기능

- 단원별 60개 실습 문제와 미션, 출력 조건, 작성 틀 안내
- 쿼리 실행·제출, 단계별 힌트, 채점 피드백
- 문법 검색(Ctrl/⌘ + K), 개념 메모, 온보딩 가이드
- 오른쪽 데이터베이스 패널에서 테이블·컬럼 확인

## 실행

`index.html`을 브라우저로 열면 돼요. GitHub Pages로도 바로 배포할 수 있어요.
